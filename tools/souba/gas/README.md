# 無料会員の仕組み（Googleスプレッドシート＋Apps Script）

会員の登録・通知の条件・自宅の登録はすべて「武蔵小杉マンション相場帳 会員管理」スプレッドシートに入る。
メールは k-minami@speard.jp の Google アカウントから自動で送られる（差出人名：武蔵小杉マンション相場帳（株式会社スピアード）、返信先：info@speard.jp）。

Apps Script（ウェブアプリ）：https://script.google.com/home/projects/1C8YJx13FMu7YPLAiaRYYSGsIsrTtzM1ql7DtKSKaeJS3AnWjbUgNlJl_/edit（プロジェクト名「相場帳 会員」）
スプレッドシート：https://docs.google.com/spreadsheets/d/1xr9JcKRMxGkDjxYYyIfjCk0LBrTx-GgILiHoYGp9SQk/edit

## 初回の設定（1回だけ、10分）

1. 上のスプレッドシートを開き、メニューの「拡張機能」→「Apps Script」を押す
2. 別のタブが開く。最初から書いてある文字（function myFunction…）をすべて消す
3. https://github.com/k-minami-hue/speard.jp/blob/main/tools/souba/gas/Code.gs を開き、右上の「Copy raw file」（四角が2つ重なったボタン）を押す
4. Apps Script の画面に貼り付けて、保存（フロッピーのボタン、または Ctrl＋S）
5. 上の「実行」ボタンの右の関数名を「setup」にして「実行」を押す
6. 「承認が必要です」と出たら「権限を確認」→ k-minami@speard.jp を選ぶ →「許可」
   （「Googleでこのアプリが確認されていません」と出た場合は「詳細」→「（安全ではないページ）に移動」→「許可」。自分で作ったものなので問題ない）
7. 右上の「デプロイ」→「新しいデプロイ」→ 歯車のボタンで「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
8. 「デプロイ」を押し、表示された「ウェブアプリのURL」（https://script.google.com/macros/s/…/exec）をコピーして Claude に送る
   → Claude が build.py の SITE["member_api"] に入れて公開する。この時点で会員機能が動き始める

コードを直したときは「デプロイ」→「デプロイを管理」→ 鉛筆のボタン →「バージョン：新バージョン」→「デプロイ」。URLは変わらない。

## 売出・値下げを通知する（伊藤さんの作業）

「物件」シートに1住戸1行で入れる。1時間以内に、条件に合う会員へ自動でメールが届く。

- 登録日：入れた日
- 種類：売出 か 値下げ
- 棟ID：一覧から選ぶ（マンション名は自動で出る）
- 所在階・専有面積・間取り・方位
- 価格（万円）：値下げのときは「変更前の価格（万円）」も入れる
- 管理費・修繕積立金（円/月）
- 取引態様：売主・代理・専属専任媒介・専任媒介・一般媒介
- 掲載ページURL：自社の物件ページ、または広告転載の承諾を得た掲載ページ
- 広告の承諾：チェックを入れた行だけ送られる

チェックを入れてよいのは、自社で媒介・売主として扱う住戸か、売主と元付業者から広告の承諾を得た住戸だけ。
レインズの図面や情報をそのまま転送しない。ポータルの掲載を転載しない。
すぐ送りたいときは、メニュー「相場帳」→「いま通知を送る（物件シート）」。

「通知状態」の見方
- 送信済み：送り終わった（「通知件数」が送った人数）
- 未記入：○○：その欄を埋めれば次の回で送られる
- 送信中（残りは次の回）：1日の送信上限に達した。翌日に残りを送る

成約・掲載終了は、相場帳の売出中の住戸（data/listings.csv）と同じく、その日のうちに止める。
会員へのメールは送ったら取り消せないため、送る前に価格と取引態様を必ず見直す。

## 自宅価格ウォッチ

相場帳の相場を四半期ごとに更新して公開すると、翌朝9時に登録者全員へ価格の目安が届く。作業はない。
会員が本登録した時点と、マイページで部屋を追加した時点でも1通届く。
登録があると info@speard.jp に「新しい会員」「自宅価格ウォッチの追加」のメールが届く。売却の見込み客なので、2〜3日以内に連絡する。

## シート

- 会員：メール・状態（仮登録＝確認メールのリンク未クリック、本登録、退会）
- 条件：売出・値下げの通知の条件
- 自宅：自宅価格ウォッチ
- 物件：通知する住戸（手で入れる）
- 棟：相場帳の棟の一覧（自動）
- ログ：送ったメールの記録

会員の個人情報が入っているため、共有は最小限にする。共有すると全シートが見える（シートの保護は編集を止めるだけで、閲覧は止められない）。
伊藤さんに「物件」の入力を任せる場合は、業務委託契約の守秘義務の範囲で共有し、「会員」「条件」「自宅」シートは保護をかけて編集できないようにする。
